# 06 里程碑与验收

## 6.1 Phase 1（Kindle 本地 MVP）
范围：
- Dashboard 首页基础框架（日期/时间）
- 首页与四象限切换
- 本地模拟数据展示

验收项：
- 能在 Kindle 正常启动
- 首页时间可实时更新
- 四象限分类展示正确

## 6.2 Phase 2（联网同步）
范围：
- Rust 服务端 + 数据库
- Dashboard 聚合接口
- 和风天气 24h API 接入
- Todo 基础管理接口（新增、编辑、删除、完成、查询）
- 后端管理页 `/admin`
- 5 分钟轮询
- done 回写服务器
- localStorage 缓存兜底

验收项：
- 轮询稳定运行
- done 成功落库
- 断网时可读缓存
- Dashboard 首页可完整渲染
- 天气接口失败时可回退默认天气数据

## 6.3 Phase 3（认证）
范围：
- 用户名密码登录页
- 会话令牌
- 任务接口鉴权
- 用户注册（后续计划，Phase 3 之后择期排期）

验收项：
- 未登录无法读写任务
- 登录后可正常轮询与 done
- 会话过期可重新登录

## 6.4 交付节奏建议
- 每个 Phase 结束输出：
  - 需求变更记录
  - 验收记录
  - 已知问题与下一阶段计划
