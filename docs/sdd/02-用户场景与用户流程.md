# 02 用户场景与用户流程

## 2.1 目标用户
- 越狱 Kindle 用户
- 希望以低刷新、低干扰方式管理任务的用户

## 2.2 核心场景
1. 打开应用先看 Dashboard 首页（时间/日期/天气）
2. 查看 24 小时天气与未来 14 天温度趋势
3. 查看 Todo 摘要并进入四象限任务页
4. 点击 done 标记完成并同步到后端
5. 应用自动轮询刷新数据
6. 网络不可用时读取本地缓存
7. 管理员在后端管理页维护 Todo 数据
8. （Phase 3）输入用户名密码登录

## 2.3 用户流程（MVP）
1. 启动应用，进入 Dashboard 首页
2. 首页展示日期、时间、天气、Todo 摘要
3. 用户查看 24 小时与未来 14 天天气
4. 用户点击进入四象限 Todo 详情
5. 点击某任务 done
6. 前端调用服务端更新状态
7. 成功后本地 UI 立即更新
8. 后台每 5 分钟轮询最新数据，刷新页面
9. 管理员可通过 `/admin` 维护任务

## 2.4 异常流程
- 网络超时：显示“同步失败，已使用缓存”
- done 回写失败：保留未完成状态并给出重试入口
- 天气接口失败：后端回退默认天气数据，前端继续可用
- 服务端错误：记录日志并展示简短错误文本
