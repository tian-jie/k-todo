# 03 功能需求

## 3.1 FR-01 Dashboard 首页（Phase 1）
- 默认进入 Dashboard 首页
- 首页显示日期、时间、周几、农历占位
- 字体大、对比明显、E-ink 友好

验收标准：
- 打开应用 2 秒内可见首页关键信息
- 时间可实时刷新

## 3.2 FR-02 首页与四象限切换（Phase 1）
- 首页可进入四象限 Todo 页面
- 四象限页可返回首页

验收标准：
- 单击后 300ms 内完成切换

## 3.3 FR-03 四象限任务展示（Phase 1）
- 按“紧急/重要”划分为四个象限：
  - Q1 紧急且重要
  - Q2 不紧急但重要
  - Q3 紧急但不重要
  - Q4 不紧急且不重要
- 每个任务至少显示标题与状态

验收标准：
- 任务归类正确率 100%

## 3.4 FR-04 天气展示（Phase 2）
- 首页展示实时天气
- 首页展示未来 24 小时天气（时间、图标、温度、风向风级）
- 首页展示未来 14 天（含温度曲线）

验收标准：
- 24 小时与 14 天信息可正常渲染
- 天气接口失败时可回退默认数据

## 3.5 FR-05 轮询同步（Phase 2）
- 前端每 5 分钟调用 Dashboard 聚合接口
- 同步成功后刷新首页与四象限
- 同步失败时读取本地缓存

验收标准：
- 轮询周期固定 300 秒
- 异常时应用不崩溃

## 3.6 FR-06 Kindle 上 done 回写（Phase 2）
- 每条任务可点击 done
- 前端调用 done 接口更新服务器
- 成功后 UI 同步为已完成

验收标准：
- 重复点击 done 不产生脏状态（幂等）

## 3.7 FR-07 Rust 服务端与数据库（Phase 2）
- 提供 Dashboard 聚合接口
- 提供任务查询与完成接口
- 提供任务新增、编辑、删除接口
- 使用关系型数据库持久化任务
- 提供健康检查接口
- 提供和风天气 24h 接入能力（通过环境变量配置）
- Phase 2 暂不实现注册与认证接口

验收标准：
- 服务可重启，数据不丢失
- Todo 的增删改查接口可用，错误码明确
- Dashboard 接口可返回首页所需字段

## 3.8 FR-08 后端管理页（Phase 2）
- 提供 Web 管理页 `/admin`
- 支持 Todo 列表的增删改查

验收标准：
- 管理页可完成 Todo 的新增/编辑/删除

## 3.9 FR-09 用户名密码登录（Phase 3）
- 提供登录输入入口
- 登录成功后保存会话信息
- 后续请求携带认证信息

验收标准：
- 未登录不可访问用户任务接口
- 会话过期后需重新登录

## 3.10 FR-10 本地缓存（Phase 2）
- 将最近一次任务列表写入 localStorage
- 启动时优先显示缓存，再异步拉取服务器

验收标准：
- 断网情况下可展示上次缓存

## 3.11 FR-11 用户注册（后续计划）
- 提供用户名密码注册入口
- 注册后可登录并绑定个人任务数据

验收标准：
- 注册输入校验完整（弱密码、重复用户名）
- 注册成功后可正常登录
