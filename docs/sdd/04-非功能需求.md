# 04 非功能需求

## 4.1 兼容性
- Kindle 前端遵循 ES5 语法
- 避免依赖 fetch、Promise、现代 CSS 特性
- 优先使用 XMLHttpRequest

## 4.2 性能
- 首屏大时钟加载 < 2 秒
- 单次轮询请求超时建议 8 秒
- 页面切换（时钟/四象限）< 300ms

## 4.3 稳定性
- 网络失败可降级到缓存
- done 失败可重试
- 服务端异常有日志可追踪

## 4.4 安全性
- Phase 3 前：接口可先使用设备级访问控制（临时）
- Phase 3：采用用户名密码 + 会话令牌
- 禁止明文日志输出密码

## 4.5 可维护性
- 文档先行，接口契约固定后再编码
- 前后端目录隔离，便于独立迭代
- 每个 Phase 有单独验收清单
